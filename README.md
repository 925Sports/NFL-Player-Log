# NFL-Player-Log

Automated NFL player logs and news for 925 Sports dashboards.

## Schedule
- News: every 12 hours
- Player logs / rosters: Tuesday + Wednesday

## Sources
- Player logs, rosters, IDs, injuries: [nflverse](https://github.com/nflverse/nflverse-data) (CC BY 4.0)
- News: ESPN unofficial JSON + ESPN RSS + RotoWire RSS
